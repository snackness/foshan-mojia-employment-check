# 求职风险核查网站

面向计划应聘佛山墨家科技有限公司的应届生和新员工，提供可直接核验的工资、合同、工时与竞业问题清单。

## 网站特点

- 纯静态 HTML、CSS、JavaScript，无构建依赖；
- 不接入广告、访问统计、外部字体或第三方脚本；
- 不公开员工姓名、联系方式、原始合同、录音或未脱敏材料；
- 每项内容标注编号、整理日期和核验状态，不替代行政、仲裁或司法结论；
- 支持移动端、键盘操作、降低动态效果和打印；
- GitHub Pages 工作流只申请发布所需的最小权限。
- 公开仓库只提供应聘者核查清单；提交学校的详细材料保留在仓库外，由持有人私下交给负责老师。

## 本地预览

在本目录启动任意静态文件服务器，然后访问 `index.html`。不要直接双击页面测试复制功能；浏览器通常只在 HTTPS 或 localhost 环境开放剪贴板权限。

## GitHub Pages 部署

1. 在 GitHub 新建一个公开仓库；
2. 将本目录内容推送到 `main` 分支；
3. 打开仓库 `Settings → Pages`，把 Source 设为 `GitHub Actions`；
4. 在 Actions 页面等待 `Deploy to GitHub Pages` 完成；
5. 访问 `https://你的用户名.github.io/仓库名/`。

请不要把 GitHub 密码、验证码、恢复码或访问令牌发给任何人。默认网址会显示 GitHub 用户名；如不希望实名关联，请使用中性用户名或组织账号。提交前建议在 GitHub 邮箱设置中启用隐私邮箱，并使用 GitHub 提供的 `noreply` 提交邮箱。

专用更正邮箱已通过 `assets/site-config.js` 配置。公开页面不设置投稿表单；仓库建议关闭 Issues 与 Discussions，避免访客误把含个人信息的材料提交到公开区域。

## 内容维护

更新事实时同时修改页面底部的更新日期，并在提交说明中简要写明变化。收到更正请求后，按照 [EDITORIAL_POLICY.md](EDITORIAL_POLICY.md) 核验和记录处理结果。首次发布前按 [上线前核查清单](ops/上线前核查清单.md) 执行，并使用 [企业核验通知模板](ops/企业核验通知模板.md) 给企业合理回应机会。
